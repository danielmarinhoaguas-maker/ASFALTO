# Mapas de Serviços — Águas de Manaus

Mapa interativo de serviços de repavimentação por bairro (exemplo), publicado com GitHub Pages.

- `index.html` — o mapa (arquivo único, sem dependências além do Leaflet/OpenStreetMap via CDN)
- `.nojekyll` — avisa o GitHub Pages para servir os arquivos como estão

## Como atualizar
1. Gere o novo `index.html` com os dados atualizados.
2. No repositório, clique em **Add file > Upload files**, envie o arquivo (substituindo o antigo) e faça o commit.
3. Em 1–2 minutos o site atualiza sozinho.

## Atenção
Em repositório **público**, qualquer pessoa vê os dados embutidos no mapa (protocolos e endereços dos serviços).
